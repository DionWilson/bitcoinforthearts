# Main Lockup — Print-Ready Vector Files

Nine separated artboards from the agency's master `BFTA-main-lockup.ai`,
extracted as individual single-page vector files for print/marketing use.

## Files

Each colorway is provided in two formats with identical content:
- `*.ai` — opens directly in Adobe Illustrator
- `*.pdf` — universal format, opens in any vector tool (Affinity Designer, InDesign, even Preview/web)

## Source

Extracted losslessly from `public/BFTA-main-lockup.ai` (the agency's
9-artboard master file) using `qpdf --pages`. All vector data, fonts, and
color profiles preserved exactly as the agency designed them.

## Use

For print materials (business cards, posters, signage, banners, swag):
- Send the `.ai` file to your designer or printer when they ask for "the logo"
- The `.pdf` version is for situations where Illustrator isn't available

The PNG/JPG versions in `public/brand-kit/main-lockups/` are for screen
use (web, email, social) and are RASTER. Use these vector files for any
print job — they scale to any size without quality loss.
