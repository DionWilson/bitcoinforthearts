# Governance

## About Bitcoin For The Arts, Inc.

Bitcoin For The Arts, Inc. is a 501(c)(3) nonprofit organization dedicated to funding sovereign creators with Bitcoin. This document outlines how the organization and this open-source project are governed.

## Financial Transparency

Bitcoin For The Arts follows the **55/30/10/5 Rule** for all incoming donations:

| Allocation    | Percentage | Purpose                                      |
|---------------|-----------|----------------------------------------------|
| Artist Grants | 55%       | Direct BTC grants to working creators        |
| Programs      | 30%       | Workshops, residencies, and co-productions   |
| Operations    | 10%       | Compliance, admin, and infrastructure        |
| HODL Vault    | 5%        | Long-term Bitcoin reserve (1 BTC by 2030)    |

### Treasury
- All finances are designed to be publicly verifiable
- Treasury reports are published quarterly
- The HODL Vault uses a 3-of-5 multisig for maximum security
- See the [Live Treasury](https://github.com/Bitcoin-For-The-Arts/bitcoinforthearts-treasury) for on-chain verification

## Open-Source Project Governance

### Decision Making

This open-source project uses a **maintainer-led** governance model:

1. **Day-to-day decisions** are made by project maintainers
2. **Significant changes** (architecture, new features, policy) are discussed in GitHub Issues or Pull Requests before implementation
3. **Community input** is welcomed and encouraged through issues, discussions, and pull requests

### Roles

| Role        | Responsibilities                                          |
|-------------|-----------------------------------------------------------|
| Maintainer  | Merge PRs, manage releases, set technical direction       |
| Contributor | Submit PRs, report bugs, suggest features                 |
| Community   | Provide feedback, test, spread the word                   |

### How Changes Are Made

1. Open an Issue describing the proposed change
2. Discuss with maintainers and community
3. Submit a Pull Request referencing the issue
4. PR is reviewed and tested by at least one maintainer
5. Approved PRs are merged into `main`

## Grant Program Governance

- Grant applications are reviewed quarterly by the grants committee
- Decisions are based on artistic merit, project feasibility, and alignment with the BFTA mission
- All grant terms are published: [Grant Terms](https://bitcoinforthearts.org/resources/grants/grant-terms.pdf)
- Grant agreements follow our [sample agreement template](public/resources/sample-grant-agreement.md)
