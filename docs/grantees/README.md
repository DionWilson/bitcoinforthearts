# Grantee work and progress

Internal record of what a grant was for, what the artist reported, and what we say in public.

One folder per grantee. Each progress note is a dated file. Receipts stay in that folder. They do not go in `public/`, because a receipt can carry an account number or a home address, and `public/` is served on the website.

Public copy (newsletter, site, social) stays on the artwork and the mission. A purchase that is not the work does not get a sentence in the newsletter just because it is on the receipt. The full receipt still lives here, so the board can see every dollar.
