## The Logo

The Bitcoin for the Arts logo is built from two typographic elements arranged into a frame:

- **"Bitcoin for the"** is set in **Neue Haas Grotesk**
- **"Arts"** is set in a **modified script** typeface

The words are arranged to **form a frame** — alluding directly to the goal of the organization: **enabling patronage**.

### Clear space rule

Minimum distance to any other graphic element should be **half the height of the "B" in BITCOIN.** Maintain this clear space in every layout — table banners, social cards, PDF letterheads, signage at events.

### "Bugs" — reduced versions

Bugs are reduced versions of the main logo. **Use them only when the main logo cannot be used** (very small placements — favicons, app icons, social profile pictures at tiny crops). **Always use the main logo where possible** to build brand equity.

## The Color Palette

Four colors. Two saturated (orange + neon green), two neutrals (cream + black). The neutrals balance the saturated colors — energetic but elegant.

| Color | HEX | RGB | CMYK | Pantone |
|---|---|---|---|---|
| **Orange** | `#FF4F14` | 255, 79, 20 | 0, 70, 90, 0 | 172 C |
| **Cream** | `#FFFAF0` | 255, 250, 240 | 2, 5, 0 | N/A |
| **Neon Green** | `#B3FF48` | 179, 255, 72 | 30, 0, 70, 0 | 2297 C |
| **Black** | `#000000` | 0, 0, 0 | 75, 68, 67, 90 | Black C |

### Usage notes

- **Always confirm Pantone codes with print production partners.**
- **Cream generally won't be printed.** It's primarily for screen + your choice of stock paper or fabric.
- **The four colors are meant to be combined.** Mix and match across layouts while keeping legibility primary.
- **The only combination to avoid:** neon green on cream, OR cream on neon green. Low contrast hampers legibility.

### Color logo combinations

The brand uses **three-color logo treatments** as the recommended application — one color for the background and two for the type. This is built into the brand intentionally and adds to the visual narrative.

## Typography

### Primary typeface — Neue Haas Grotesk

**Neue Haas Grotesk**, originally designed by Haas Type Foundry, is a **modernist sans-serif rooted in Swiss design**, known for clarity, neutrality, and balanced proportions. Clean, highly legible voice with a timeless, understated feel across print and digital.

### Type system

| Weight | Use case |
|---|---|
| **Neue Haas Grotesk 45 Light** (all caps) | Headlines — elevated, refined tone |
| **Neue Haas Grotesk 65 Medium** | Subheads + key details + discipline labels |
| **Neue Haas Grotesk Roman** | Body copy — readability priority |

The hierarchy is intentional: Light caps for headlines, Medium for support, Roman for body — clean, confident, legible.

### Discipline lockups

Each artistic discipline (Music / Dance / Theater / Film / Visual Art / Writing / Storytelling) is expressed through a consistent typographic system using **Neue Haas Grotesk 65 Medium** for clear, bold labeling. Each lockup pairs one of the BFTA marks with the discipline name — immediate recognition + flexibility across applications.

## QR Code Treatment

QR codes balance brand expression with functionality. Custom styling, color, and logo integration are encouraged. **But codes must remain easily scannable** across devices and lighting conditions.

Always test before use. Maintain sufficient contrast, clear spacing, and legibility — performance can never be compromised for visual style.

## The Brand World — Voice + Visual Tone

The brand world comes to life through:

- **Bold layering** — graphic elements stacked, intersecting
- **High-contrast color combinations** — saturated + neutral pairings
- **Dynamic compositions** — graphic elements can **overlap, rotate, and interact** to create a sense of energy and disruption
- **Clear typographic hierarchy** maintained throughout — the energy is in the layout, the clarity is in the type

Applications scale from **posters to environmental placements** while staying rooted in the system's vibrant palette and structured type.

### Voice descriptors (for writing about the brand publicly)

When writing about the BFTA brand in articles, newsletters, or sponsor materials, these are the descriptors that match the actual brand language:

- **Clean, deliberately minimal** (the lockup itself)
- **Modernist Swiss design lineage** (the typography)
- **Energetic yet elegant** (the saturated + neutral color balance)
- **Patronage-as-frame** (the conceptual reasoning behind the lockup arrangement)
- **Bold, layered, dynamic** (the brand world / compositional treatment)
- **Clear, confident, legible** (the type hierarchy)
- **Modern, deliberate, built to last** (the overall positioning)
