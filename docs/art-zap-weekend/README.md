# Art + Zap Weekend — Sponsor Package

Complete planning package for the Art + Zap Weekend fundraiser:
**2 days × 4 hours, 21 artists, broadcast on YouTube + X + Nostr (Zap.Stream),
culminating in a live in-person finale at Pubkey NYC.**

## Files

| File | Use it when... |
|---|---|
| `00-one-page-pitch.md` | You need to print **one page** for a sponsor meeting. This is the leave-behind. |
| `01-sponsor-leave-behind.md` | You want the **full multi-page** sponsor proposal with tiers, in-kind menu, and team credibility. |
| `02-sponsor-tiers-and-budget.md` | You need the **rationale** behind the tier pricing and a sponsor pushes back on $25K. |
| `03-podcaster-host-plan.md` | You're recruiting **podcaster hosts** (2 per day) — includes outreach script and target archetypes. |
| `04-spreadsheet-update.md` | You need to **update the Google Sheet** — instructions for importing each CSV tab. |
| `tabs/sponsors-tiers.csv` | Sheet tab: tier definitions and slot tracker |
| `tabs/sponsors-pipeline.csv` | Sheet tab: sponsor outreach pipeline |
| `tabs/in-kind.csv` | Sheet tab: in-kind ask tracker |
| `tabs/podcaster-hosts.csv` | Sheet tab: host outreach tracker |
| `tabs/artists.csv` | Sheet tab: 21-artist roster with day/slot |
| `tabs/schedule-saturday.csv` | Sheet tab: Saturday minute-by-minute rundown |
| `tabs/schedule-sunday.csv` | Sheet tab: Sunday rundown including Pubkey finale |
| `tabs/budget.csv` | Sheet tab: budget with floor/target/stretch scenarios |
| `tabs/tasks-owners.csv` | Sheet tab: who owns what, by deadline |

## Quick start for the Tuesday pitch

1. Open `00-one-page-pitch.md` and fill in `[DATE]`, `[LN address]`, `[BTC address]`, `[npub]`, `[EIN]`. Print 5 copies.
2. Skim `02-sponsor-tiers-and-budget.md` so you can defend the $5K – $25K range and the 9-slot cap.
3. Have `01-sponsor-leave-behind.md` ready as a PDF on your phone for any sponsor who wants more depth.
4. Update the Google Sheet using `04-spreadsheet-update.md` and the CSVs in `tabs/`.

## Format decisions baked into this package

- **2 days × 4 hours** (Sat + Sun, 1–5 pm ET) — chosen for global reach, manageable production, and Sunday → Pubkey finale handoff
- **21 artists, 10 + 11 split** across the two days
- **2 podcaster hosts per day** (4 total + 2 backups)
- **9 sponsor slots maximum** ($25K Title + 3 × $10K Supporting + 5 × $5K Friend)
- **Pubkey NYC** as the in-person finale venue (with 1 backup confirmed)

If any of these change, update the relevant file and the corresponding CSV tab.
