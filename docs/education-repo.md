# Education Repository Setup

This guide tracks the recommended setup for the public BFTA education
repository in the Bitcoin-For-The-Arts GitHub organization.

## Create the repo
Recommended settings:
- Name: education
- Visibility: Public
- Initialize with a README

## Add an open license (required)
Use Creative Commons Attribution 4.0 International (CC BY 4.0).

LICENSE contents (recommended minimal text):

Creative Commons Attribution 4.0 International

This work is licensed under the Creative Commons Attribution 4.0 International
License. To view a copy of this license, visit
https://creativecommons.org/licenses/by/4.0/ or send a letter to Creative
Commons, PO Box 1866, Mountain View, CA 94042, USA.

## Webinar materials layout
Create a folder for each webinar:

webinars/2026-02-08/
  README.md
  education-webinar.pdf

## Webinar README template
Use a short note that captures the title, date, contents, and license:

# Bitcoin For The Arts Education Webinar

Date: 2026-02-08

## Contents
- education-webinar.pdf

## License
Licensed under CC BY 4.0 (see LICENSE at the repo root).

## PDF upload
Place the webinar PDF in the same folder as the README. If the file name
differs, update the README contents list to match.
