# Bitcoin For The Arts, Inc. Press Kit

This folder contains a complete, ready-to-send press kit tailored for arts media outreach.

## What is included

1. `one-page-press-kit.md`  
   A concise one-page media sheet you can paste into email or export to PDF.
2. `fact-sheet.md`  
   Organization background, founder bio, program details, and boilerplate.
3. `media-assets-and-story-angles.md`  
   Curated image/logo list and publication angles (including BroadwayWorld- and Playbill-ready hooks).
4. `email-pitch-templates.md`  
   Copy/paste pitch emails for BroadwayWorld, Playbill, and follow-up.
5. `press-release-draft.md`  
   A 400-500 word release draft for immediate distribution.
6. `outreach-playbook.md`  
   Step-by-step submission workflow and publication sequence.

## Fast start (recommended)

1. Start with `one-page-press-kit.md`.
2. Attach 2-4 images from `media-assets-and-story-angles.md`.
3. Use the subject line + template in `email-pitch-templates.md`.
4. Submit to BroadwayWorld first, then send a personalized pitch to Playbill.
5. Follow up once after 7-10 days.

## Export tip

To create a polished PDF quickly:

1. Open `one-page-press-kit.md` in your editor preview.
2. Print to PDF with margins set to "narrow".
3. Keep final file size under 5-8 MB if attaching high-resolution images.
